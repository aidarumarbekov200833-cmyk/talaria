ИИ-оффер: скелет письма

Опишите, как примерно должен выглядеть оффер. Talaria учитывает тематику, размер канала и последние ролики, а затем готовит несколько разных вступлений. В рассылке персонализация выполняется автоматически для каждого лида: там достаточно переключить тип оффера на «ИИ-оффер».

Пишите как обычное письмо: структура, предложение и вопрос в конце сохранятся, а детали ИИ подставит по каналу. Плейсхолдеры те же, что в обычном оффере.
Больше материалов — точнее текст и дороже запрос.

Как получить ключ YouTube API

Ключ бесплатный. Google даёт каждому проекту 10 000 единиц квоты в сутки — хватает примерно на 100 страниц поиска. Вся процедура занимает 3–4 минуты.

Открыть Google Cloud Console → Официальная инструкция Google
1
Откройте Google Cloud Console и создайте проект
Зайдите на console.cloud.google.com под любым Google-аккаунтом. Вверху слева нажмите на выбор проекта и затем «New project» — имя проекта может быть любым.
Создать проект →
2
Включите YouTube Data API v3
В меню слева: APIs & Services → Library. В поиске наберите «YouTube Data API v3», откройте карточку и нажмите Enable.
Открыть YouTube Data API v3 →
3
Создайте ключ
Там же слева: APIs & Services → Credentials. Сверху нажмите + Create credentials и выберите API key.
Открыть Credentials →
4
Скопируйте ключ
Появится окно «API key created» — ключ начинается с AIza…. Нажмите иконку копирования. Ограничения (restrictions) можно не настраивать.
5
Вставьте ключ сюда
Вернитесь в эту панель, вставьте ключ в поле «Ключ API», дневную квоту оставьте 10 000 и нажмите Добавить ключ. Кнопка «Проверить» рядом с ключом сделает настоящий запрос к YouTube и подтвердит, что всё работает. Нужно больше квоты — создайте второй проект и добавьте второй ключ: квоты суммируются.

Балл лида — что это?

Оценка канала от 0 до 100: насколько он похож на живой и активный. Считается по открытым данным YouTube, по ней сортируется таблица и работает фильтр «минимальный балл» в рассылке.

70+
Тёплый — живая аудитория и стабильные просмотры. Писать в первую очередь.
40–69
Средний — канал рабочий, но что-то проседает: аудитория или просмотры.
<40
Холодный — маленький, пустой или накрученный канал. Ответ маловероятен.
40Вовлечённость: средние просмотры на ролик. Главный отсев накруток — подписчиков купить легко, стабильные просмотры нет.
30Аудитория: число подписчиков. Скрытый счётчик не обнуляет балл — счётчик часто скрывают именно крупные каналы.
15Активность: есть ли на канале заметное число роликов.
15Релевантность: найден ли канал по вашему ключевому слову.

Шаг 1. Соберите базу каналов

В разделе «Поиск» задайте ключевые слова и фильтры — найденные YouTube-каналы сохранятся в базу лидов.

  • Готовый список можно залить кнопкой «Импорт CSV».
  • Каждый лид получает балл 0–100: аудитория, вовлечённость, активность.

Шаг 2. Оффер и рассылка

Создайте оффер — шаблон сообщения с подстановками, затем запустите рассылку по выбранной базе.

  • Повторно одному человеку ничего не уйдёт: отправки запоминаются.
  • Рассылку можно отложить на дату — её запустит планировщик.

Шаг 3. Прогрейте аккаунт

Новый Telegram-аккаунт нельзя сразу нагружать рассылкой. В «Настройках» включите «Прогрев» — параметры применятся автоматически.

  • Ручные лимиты, дни и паузы заполнять не нужно.
  • Начать можно с тестового сообщения себе.

Шаг 4. Ключ YouTube API

Последнее и самое важное: без бесплатного ключа Google поиск лидов не запустится. Нажмите «Открыть настройки» — там же откроется инструкция со ссылками и картинками.

  • Ключ бесплатный: 10 000 единиц квоты в сутки на проект.
  • Вся процедура в Google Cloud занимает 3–4 минуты.
